The Key Insight Everyone is racing to automate documentation. AI scribing is becoming table stakes ($49-$129/mo standalone tools). HealUI is the only platform using AI for clinical reasoning — differential diagnosis, treatment protocol generation, multi-condition management. This is a different race entirely.

How Hard Is It for Incumbents to Catch Up?

  • AI scribing: Easy. Already happening everywhere. Table stakes by end of 2026.
  • Clinical intelligence (diagnosis + protocols): Very hard. Requires restructured data models, PT-specific training data, clinical validation, and a fundamentally different product philosophy.
  • Bilateral/laterality architecture: Very hard. This is a schema-level change that touches every entity, every API, every UI component. Cannot be bolted on.
  • Multi-condition episode model: Very hard. Requires separating assessment from conditions — a core data model redesign.
The Bottom Line HealUI is not competing in the "PT EMR + AI scribe" category. It's creating the "AI clinical intelligence for physiotherapy" category. The competitors adding AI scribes are optimizing documentation. HealUI is reimagining clinical reasoning. These are different products serving different needs, and the incumbents' legacy architectures make catching up extremely difficult without a ground-up rebuild.
