# Screening Hooks

This directory is prepared for extracted custom hooks from large chatbot components.

## Planned Hooks:
- `useScreeningFlow.ts` - Manages screening flow state
- `useQuestionLogic.ts` - Handles question rendering and validation
- `useDiagnosisEngine.ts` - Computes diagnosis from answers
- `useBodyMapState.ts` - Manages body map selections
- `useChatHistory.ts` - Manages chat message history
